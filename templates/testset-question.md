# Разметка вопроса тестового набора

Один файл на вопрос или таблица из таких строк. Размечает человек, знающий регламенты.

**ID:** ______ **Формулировка:** ______

**Тип:** [ ] аккуратный [ ] разговорный/опечатки [ ] без ответа [ ] по закрытому документу (роль: ______)

**Релевантные документы:**

| Документ | Оценка (2 = содержит ответ, 1 = полезен частично) |

|  |  |
|  |  |

**Факт эталонного ответа** (подстрока или «вариант|вариант»): ______

**Где найден факт:** документ ______, раздел ______

**Кем и когда размечено:** ______ **Спорно?** [ ] нет [ ] да, примечание: ______
