# Как участвовать

Книга и лаборатория принимают замечания и правки. Одно изменение на один pull request: так рецензия проходит быстро, а автор замечания попадает в CHANGELOG.

## Что можно сообщать

- **Ошибка в книге**: опечатка, неверное число, неточный факт, непонятное место. Откройте issue по шаблону «Ошибка в книге» с номером страницы и цитатой.
- **Ошибка в лаборатории**: команда падает, тест не проходит, число расходится с текстом. Шаблон «Ошибка в лаборатории», приложите вывод целиком.
- **Предложения тем**: чего не хватает книге. Опишите задачу читателя, которую закрывает тема.

## Как устроена книга

Исходники глав лежат в `chapters/NN-slug.md`, правила языка и разметки в [WRITING.md](WRITING.md). Каждое число в тексте подставляется из `build/numbers.json` (команда `npm run numbers`); руками числа не вписываются. Сборка падает на отсутствующем ключе, CI повторяет сборку PDF на каждый коммит.

## Что считается проверкой

Перед отправкой прогоните и приложите вывод:

```bash
npm test          # все тесты зелёные
npm run numbers   # числа пересчитаны
npm run build     # PDF собирается (нужны pandoc, poppler-utils, Chrome)
```

Если меняли код лаборатории, обновите тесты: тесты проверяют числа книги. Если число в тексте меняется, в PR должно быть видно новое значение и причина. Сравнение методов честно только на тестовом наборе из `src/questions.ts`: новые вопросы добавляйте с разметкой и фактом ответа.

## Чего мы не делаем

- Не добавляем внешние зависимости: лаборатория работает на чистом Node.js 24 без сети.
- Не убираем оговорки «что моделируется честно, а что нет»: учебные эмбеддинги остаются игрушечными, и это сказано прямо.
- Не вносим числа в текст руками.
